## Fiddler </br>
```Manipulate Ultima Online™ Game Files to Customize Game Assets for uoAvox```</br>

---
The purpose of this software is so users can manipulate the Ultima Online™ Game asset files. This action is required if users want to fully 
customize their creative experience. With this program you can essentially replace all assets in the game; animation, artwork, sounds, 
lighting, special spell affects, ground tiles, floor tiles, textures, gumps, and more!
